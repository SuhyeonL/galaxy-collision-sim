## N-Body

# 변수
- G
중력 상수
시뮬레이션에서는 보통 1.0으로 설정

- N
입자 개수

- m_j
j 번째 입자의 질량

- r_i, r_j
입자 i, j의 위치 벡터
(r_j - r_i)는 i에서 j를 바라보는 방향 벡터 -> 두 입자 사이의 거리와 방향을 나타냄

- ε
softening parameter
두 입자가 극도로 가까워지면 분모가 0에 가까워져서 가속도가 무한대로 발산하는걸 방지하기 위해 사용
보통 입자 간 평균 거리의 1/10 정도로 설정

N-Body 알고리즘
- 입자 하나당 나머지 N-1개 입자들의 중력을 전부 더해야 함 -> 이중 루프 필요
- 모든 입자는 주변 모든 입자로부터 중력을 받음
